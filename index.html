From a file

Google Calendar

On a computer, open calendar.google.com → Settings → Import & export → Export. Choose the downloaded .zip file here; there's no need to unzip it.

Apple Calendar (Mac / iCloud)

Mac: select the calendar, then File → Export → Export… to get an .ics file. iPhone: share the calendar as a Public Calendar in iCloud and use the link below.

Outlook

Outlook on the web: Settings → Calendar → Shared calendars → Publish a calendar, then copy the ICS link into the link section below. Outlook desktop: File → Save Calendar as .ics.

Notion

In your Notion calendar database, tap ••• → Export → Markdown & CSV. Choose the .csv (or .zip) file here. The name and date columns are found automatically.

From a subscription link

Where is the link?

Google: Calendar settings → Integrate calendar → Secret address in iCal format. Apple: Share calendar → Public Calendar → copy the webcal:// link. Outlook: the ICS link from Publish a calendar. Notion Calendar: any calendar that gives you an .ics link.

Subscriptions sync again when the app opens. A secret link lets anyone read that calendar, so don't share it.
